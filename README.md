NFL Attendance Analysis (2000–2019)
A data analysis project exploring NFL fan attendance trends using MySQL and Power BI.
Tools Used

MySQL — data cleaning and analysis
Power BI — dashboard and visualizations

Dataset
NFL weekly attendance data from 2000–2019, covering all 32 teams. Includes home, away, and weekly attendance figures.
Questions Explored

Which teams draw the most fans at home?
How has league-wide attendance changed over 20 years?
Which seasons were each team's best and worst for attendance?
Which teams have the strongest home crowd advantage?
How does attendance fluctuate week to week throughout a season?

Key Findings

League attendance peaked around 2015 and dipped during the 2008 financial crisis and after the 2016 neal down
The Cowboys consistently lead in average home attendance
The Redskins (now Commanders) have the largest home vs. away attendance gap in the league
Weekly attendance drops noticeably around weeks 9–11 mid-season
